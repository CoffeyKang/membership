# membership
Membership system for Hair Salon.

## Overview
This is a membership system designed specifically for the hair salon. The system allows only the super - admin (the salon owner) to create new users. Once created, users can log in to the system to create new members.

## Key Features
- **Super Admin Control**: Only one super admin (the hair salon owner) has the privilege to create new users.
- **User Login**: Registered users can log in to the system.
- **Member Creation**: Logged - in users can create new members for the hair salon.
- **Member Management**: Users can view and manage their own member profiles, including balance and payment history.
